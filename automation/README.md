# Deployment Automation

## Objective

This deployment script automates installation and deployment of the observability monitoring stack.

The goal is to reduce manual setup effort and improve deployment consistency.

---

# Features

- System package updates
- Docker installation
- Docker Compose installation
- Container deployment
- Service validation

---

# Usage

From the repository root:

```bash
chmod +x automation/deploy.sh
./automation/deploy.sh
```
